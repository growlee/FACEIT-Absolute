# FACEIT Absolute 2.6.0

[Русский](#русский) · [English](#english)

## Русский

**Новый редактор фона · Автоподключение к серверу · Автоотправка звуков · Быстрее профиль**

### Что нового после 2.5.0

- **Новый редактор фона профиля.** Переработаны кадрирование и обрезка видео:
  маркеры обрезки всегда доступны, сохранение надёжнее восстанавливается после
  обрыва, рамка кадрирования использует цвет акцента. Статичные фото больше
  не сжимаются до 720p и сохраняют детализацию до 1080p.
- **Новые форматы фона.** Видео в H.265/HEVC и AV1 (включая 10-битные записи
  с телефонов и программ захвата) теперь принимаются. GIF и анимированный WebP
  сохраняются как чёткое MP4 до 1080p. Обработка выполняется на сервере проекта.
- **Автоподключение к серверу матча.** Новая настройка один раз за матч
  нажимает подключение, когда сервер готов. По умолчанию выключена.
- **Автоотправка звуков в чат.** Отдельные переключатели для чата команды и
  общего чата отправляют выбранный звук при входе в комнату матча — после
  подтверждённого сообщения о позиции, без повторной отправки. Черновики и
  вложения сохраняются. В превью звука видно, сколько уже проиграно.
- **Клан-тег.** Упрощены настройки собственного клан-тега, добавлен размер
  шрифта 75–150 % (локальная настройка этого браузера).
- **Лобби и поиск матча.** Нативная статистика FACEIT объединена с карточкой
  игрока; кольцо аватара, рамка Party Finder, индикатор матча и кнопки игры
  используют цвет обводки расширения; исправлены наложения соединителей группы.
- **Оформление профиля.** Единые обводки и обесцвечивание верхних карточек,
  сезонной графики и подсказки Plus; чужие шрифты и цвет текста применяются
  только к просматриваемому профилю.
- **Производительность.** Устранены многосекундные повторные проходы отрисовки
  профиля, на которые жаловались в отзывах при удалении 2.5.0.
- **Исправления.** Автоматические звуки находят новые чаты FACEIT; выход из
  аккаунта не отменяется параллельным чтением сессии; согласия и границы
  состояния уточнены после аудита; оформление панели «Звуки» совпадает с общей.
- **Библиотека фонов** (сайт): сортировка по популярности, новизне и названию.

Для Chrome, Edge и Opera теперь требуется Chrome/Chromium 127 или новее.

### Установка и обновление

Для Chrome, Edge или Opera распакуй соответствующий GitHub ZIP, открой
`chrome://extensions`, `edge://extensions` или `opera://extensions`, включи режим
разработчика и выбери «Загрузить распакованное расширение» → папку с
`manifest.json`. Для обновления замени файлы в прежней папке и нажми «Обновить»,
сохранив установленное расширение и его локальные настройки.

**Firefox:** обычная установка доступна через
[Firefox Add-ons](https://faceit.eelworg.ru/r/PmGEU43eYuhbEofi).
Firefox ZIP не подписан Mozilla и подходит для временного тестирования через
`about:debugging` → «Этот Firefox» → «Загрузить временное дополнение».
Минимум: Firefox 140; заявленный минимум Android — 142.

Некоторые функции требуют подключения FACEIT и/или Absolute Premium; условия
показаны в расширении. FACEIT Absolute — независимый проект, не связанный с FACEIT.

## English

**New background editor · Server auto-connect · Sound auto-send · Faster profiles**

### Changes since 2.5.0

- **New profile background editor.** Reworked cropping and video trimming:
  trim handles stay reachable, saves recover more reliably after interruptions,
  and the crop frame uses the accent color. Static photos are no longer
  downscaled to 720p and keep detail up to 1080p.
- **More background formats.** H.265/HEVC and AV1 videos (including 10-bit
  phone and game-capture recordings) are now accepted. GIF and animated WebP
  are stored as sharp MP4 up to 1080p. Processing runs on the project server.
- **Match server auto-connect.** A new setting clicks connect once per match
  when the server is ready. Off by default.
- **Sound auto-send.** Separate team-chat and all-chat switches send the
  selected sound when you enter a match room, after the confirmed position
  message and never twice. Drafts and attachments are preserved. The sound
  preview now shows elapsed playback.
- **Clan tag.** Simplified own clan-tag settings with a local 75–150% font size.
- **Lobby and matchmaking.** Native FACEIT stats merge into the player card;
  the avatar ring, Party Finder border, match indicator and play buttons use
  the extension outline color; party connector overlaps are fixed.
- **Profile customization.** Consistent outlines and desaturation for upper
  cards, season artwork and the Plus tooltip; foreign fonts and text color
  apply only to the viewed profile.
- **Performance.** Removed repeated multi-second profile-render passes reported
  in 2.5.0 uninstall feedback.
- **Fixes.** Automatic sounds resolve FACEIT's newer chats; logout is no longer
  undone by a concurrent session read; consent and state boundaries were
  tightened after an audit; the Sounds panel matches the general panel style.
- **Background library** (website): sort by popularity, newest or title.

Chrome, Edge and Opera now require Chrome/Chromium 127 or newer.
