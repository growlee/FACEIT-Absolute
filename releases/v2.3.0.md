# FACEIT ABSOLUTE 2.3.0

[Русский](#русский) · [English](#english)

## Русский

**Видео профиля до 30 секунд · Компактные клан-теги · Улучшенное сохранение цветов**

### Что нового после 2.2.0

- **Видео профиля до 30 секунд.** Выбор фрагмента видео, подготовка подходящих H.264/VP9 исходников до 4K и 50 МиБ; результат — до 1080p, 30 FPS и 20 МиБ. GIF и WebP сохраняют ограничение восемь секунд. Обработка зависит от формата и размера файла и может занимать время.
- **Компактное меню клан-тегов.** Обновлённое управление тегами с автосохранением; цвет сохраняется при изменении в палитре.
- **Удобнее настройка цветов.** Исправлены области нажатия, отступы и предпросмотр заливки; отложенный ответ сохранения больше не должен сбрасывать текущий предпросмотр.
- **Более последовательное оформление FACEIT.** Исправления акцентов поиска матча, боковых панелей CS2 и прозрачности правой панели аккаунта.
- **Обновлённое знакомство с расширением.** Страница приветствия с подсказкой закрепления расширения, обратной связью по действию и поддержкой уменьшенного движения.
- **Дополнительные исправления.** Обнаружение поздно появившихся карт и предложений матча, необязательный опрос при удалении, сохранение ожидающих диагностических записей.

### Установка и обновление

1. Для Chrome, Edge или Opera распакуй соответствующий ZIP.
2. Открой `chrome://extensions`, `edge://extensions` или `opera://extensions`.
3. Включи режим разработчика, нажми «Загрузить распакованное расширение» и выбери папку с `manifest.json`.
4. При обновлении существующей ручной установки замени файлы в прежней папке и нажми «Обновить». Сохрани установленное расширение, чтобы сохранить локальные настройки.

**Firefox:** для обычной установки используй Firefox Add-ons. ZIP не подписан Mozilla; он предназначен для ручной отправки в магазин и временного тестирования через `about:debugging` → «Этот Firefox» → «Загрузить временное дополнение». Требуется Firefox 140+; заявленный минимум Android — 142+.

### Для загрузки в магазины

- **Google Chrome Web Store:** загрузи `FACEIT-ABSOLUTE-2.3.0-Chrome.zip` в существующую карточку расширения.
- **Mozilla Add-ons:** загрузи `FACEIT-ABSOLUTE-2.3.0-Firefox.zip` как новую версию существующего дополнения. Gecko ID сохранён. Подпись и одобрение выдаёт Mozilla.

Некоторые функции требуют подключения FACEIT и/или Absolute Premium; условия показаны в расширении. FACEIT Absolute — независимый проект, не связанный с FACEIT.

## English

**Profile videos up to 30 seconds · Compact clan tags · Improved color saving**

### Changes since 2.2.0

- **Profile videos up to 30 seconds.** Select a segment and prepare supported H.264/VP9 sources up to 4K and 50 MiB; output is capped at 1080p, 30 FPS and 20 MiB. GIF/WebP keep their eight-second limit. Processing time depends on the input.
- **Compact clan-tag menu.** Refreshed controls with autosave, including saving color changes while using the picker.
- **Improved color controls.** Corrected click targets, spacing and fill previews; delayed save responses preserve the active preview.
- **FACEIT styling fixes.** Matchmaking accents, CS2 sidebar backgrounds and the right account rail follow customization more consistently.
- **Updated welcome experience.** Extension-pinning guidance, action feedback and reduced-motion support.
- **Other fixes.** Late map and match-offer detection, an optional uninstall survey, and preservation of pending diagnostic records.

### Downloads and installation

**[Chrome](https://github.com/growlee/FACEIT-Absolute/releases/download/v2.3.0/FACEIT-ABSOLUTE-2.3.0-Chrome.zip) · [Firefox](https://github.com/growlee/FACEIT-Absolute/releases/download/v2.3.0/FACEIT-ABSOLUTE-2.3.0-Firefox.zip) · [Edge](https://github.com/growlee/FACEIT-Absolute/releases/download/v2.3.0/FACEIT-ABSOLUTE-2.3.0-Edge.zip) · [Opera](https://github.com/growlee/FACEIT-Absolute/releases/download/v2.3.0/FACEIT-ABSOLUTE-2.3.0-Opera.zip) · [SHA-256](https://github.com/growlee/FACEIT-Absolute/releases/download/v2.3.0/SHA256SUMS.txt)**

For Chromium browsers, extract the ZIP, open the browser's extensions page, enable Developer mode and choose **Load unpacked**. Select the folder containing `manifest.json`. To update, replace the files in the existing folder and click **Reload**, keeping the extension installed to preserve local settings.

For regular Firefox installation, use [Firefox Add-ons](https://addons.mozilla.org/en-US/firefox/addon/faceit-absolute/). This ZIP is unsigned and is intended for temporary testing or manual Mozilla Add-ons submission. Temporary loading is available through `about:debugging` → **This Firefox** → **Load Temporary Add-on**. Requires Firefox 140+; the declared Android minimum is 142+.

For store submission, use the **Chrome ZIP for Chrome Web Store** and the **Firefox ZIP for Mozilla Add-ons**. This GitHub publication does not submit either package to a store or claim store approval. Some features require a connected FACEIT account and/or Absolute Premium, as indicated in the extension.
