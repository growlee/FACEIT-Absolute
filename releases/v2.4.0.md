# FACEIT ABSOLUTE 2.4.0

[Русский](#русский) · [English](#english)

## Русский

**Оформление лобби · Клан-теги на аватарах · Свой текст кнопки поиска**

### Что нового после 2.3.0

- **Оформление CS2-лобби.** Фон профиля, прозрачность секций и внутренних поверхностей, настройки видимости статистики, карт, чата и заданий. Исправлены переходы между страницами, обновление статистики карт и цветовые акценты.
- **Клан-теги.** Размещение на аватарах и перед именами игроков, полное название при наведении, видимость только собственного тега. Исправлены русские и английские подписи, доступные названия элементов и статусы.
- **Свой текст кнопки поиска матча.** Настройка сохраняется между переходами и перезагрузками; очистка возвращает штатную надпись. Состояния поиска и доступные подписи сохраняются.
- **Аудио и автопик.** Исправлено определение активной комнаты после SPA-переходов и обнаружение вложений чата; поля сообщений автопика скрываются, когда соответствующая отправка отключена.
- **Оформление профиля и меню.** Исправлены обводка графика ELO, материалы последних результатов и контраст метки beta; уведомления popup стали компактнее. Кнопки Connect/Reconnect FACEIT переключаются вместе с языком.
- **Диагностика.** Учитывается прокрутка внутренних областей, сохраняется ограниченный контекст ошибок. Автоматические отчёты включены по умолчанию при отсутствии настройки; явное отключение сохраняется. Выключатель находится в разделе «Информация».

Автоматические отчёты содержат ограниченные диагностические данные и идентификатор установки. Полные URL, cookies, токены, свободный текст ошибок и сырые стеки в них не отправляются. Действуют лимиты отправки и группировки; подробности — в [политике приватности](https://faceit.eelworg.ru/privacy).

### Установка и обновление

1. Для Chrome, Edge или Opera распакуй соответствующий ZIP.
2. Открой `chrome://extensions`, `edge://extensions` или `opera://extensions`.
3. Включи режим разработчика, нажми «Загрузить распакованное расширение» и выбери папку с `manifest.json`.
4. При обновлении существующей ручной установки замени файлы в прежней папке и нажми «Обновить». Сохрани установленное расширение, чтобы сохранить локальные настройки.

**Firefox:** для обычной установки используй Firefox Add-ons. ZIP не подписан Mozilla; он предназначен для ручной отправки в магазин и временного тестирования через `about:debugging` → «Этот Firefox» → «Загрузить временное дополнение». Требуется Firefox 140+; заявленный минимум Android — 142+.

### Для загрузки в магазины

- **Google Chrome Web Store:** загрузи `FACEIT-ABSOLUTE-2.4.0-Chrome.zip` в существующую карточку расширения.
- **Mozilla Add-ons:** загрузи `FACEIT-ABSOLUTE-2.4.0-Firefox.zip` как новую версию существующего дополнения. Gecko ID сохранён. Подпись и одобрение выдаёт Mozilla.

Некоторые функции требуют подключения FACEIT и/или Absolute Premium; условия показаны в расширении. FACEIT Absolute — независимый проект, не связанный с FACEIT.

## English

**Lobby customization · Avatar clan tags · Custom matchmaking button text**

### Changes since 2.3.0

- **CS2 lobby customization.** Profile backgrounds, section and inner-surface transparency, and visibility controls for statistics, maps, chat and missions. Improved page transitions, map-statistics updates and color accents.
- **Clan tags.** Avatar and player-name placement, full-name hover tooltips, and own-tag-only visibility. Corrected Russian/English labels, accessible names and statuses.
- **Custom matchmaking button text.** The preference survives navigation and reloads; clearing it restores the native label. Queue states and accessible labels are preserved.
- **Audio and autopick.** Fixed active-room detection after SPA navigation and chat-attachment discovery. Autopick message fields are hidden when their send option is disabled.
- **Profile and popup styling.** Improved ELO-chart outlines, recent-result materials and beta-badge contrast; more compact popup notices. Connect/Reconnect FACEIT buttons now follow language changes.
- **Diagnostics.** Internal scrolling and limited error context are recorded. Automatic error reports are enabled by default if no preference exists; an explicit opt-out is preserved. The switch is in Information.

Automatic reports contain limited diagnostic data and an installation identifier. They exclude full URLs, cookies, tokens, free-form error text and raw stacks. Sending and grouping limits apply; see the [privacy policy](https://faceit.eelworg.ru/privacy).

**[Chrome](https://github.com/growlee/FACEIT-Absolute/releases/download/v2.4.0/FACEIT-ABSOLUTE-2.4.0-Chrome.zip) · [Firefox](https://github.com/growlee/FACEIT-Absolute/releases/download/v2.4.0/FACEIT-ABSOLUTE-2.4.0-Firefox.zip) · [Edge](https://github.com/growlee/FACEIT-Absolute/releases/download/v2.4.0/FACEIT-ABSOLUTE-2.4.0-Edge.zip) · [Opera](https://github.com/growlee/FACEIT-Absolute/releases/download/v2.4.0/FACEIT-ABSOLUTE-2.4.0-Opera.zip) · [SHA-256](https://github.com/growlee/FACEIT-Absolute/releases/download/v2.4.0/SHA256SUMS.txt)**

For Chromium browsers, extract the ZIP, open the browser's extensions page, enable Developer mode and choose **Load unpacked**. Select the folder containing `manifest.json`. To update, replace the files in the existing folder and click **Reload**, keeping the extension installed to preserve local settings.

For regular Firefox installation, use [Firefox Add-ons](https://addons.mozilla.org/en-US/firefox/addon/faceit-absolute/). This ZIP is unsigned and is intended for temporary testing or manual Mozilla Add-ons submission. Temporary loading is available through `about:debugging` → **This Firefox** → **Load Temporary Add-on**. Requires Firefox 140+; the declared Android minimum is 142+.

For store submission, use the **Chrome ZIP for Chrome Web Store** and the **Firefox ZIP for Mozilla Add-ons**. This GitHub publication does not submit either package to a store or claim store approval. Some features require a connected FACEIT account and/or Absolute Premium, as indicated in the extension.
