# FACEIT Absolute 2.5.0

[Русский](#русский) · [English](#english)

## Русский

**Энергосбережение в матче · Положение клан-тега · Улучшенное оформление**

### Что нового после 2.4.0

- **Энергосбережение во время своего матча.** Можно отключать декоративные
  эффекты или приостанавливать функции расширения на время матча. После его
  окончания расширение восстанавливает работу. Снижение нагрузки CPU/GPU
  численно не измерялось.
- **Положение собственного клан-тега.** Размещение на аватаре или под ним;
  вертикальная настройка на аватаре. Исправлены отступы рядом с именем игрока.
- **Оформление профиля.** Улучшен чёрно-белый режим, включая значки, навигацию
  и историю матчей; сохранены цвета и настройки при его отключении.
- **Кнопка поиска и текущий матч.** Длинный пользовательский текст переносится
  на строки, сохраняются цветовые акценты и читаемость уведомлений.
- **Аудио и переходы по сайту.** Исправлена работа с устаревшим контекстом
  расширения после перезагрузки. Библиотека звуков поддерживает разворачиваемые
  карточки и внешний вид профиля; это отдельная веб-страница.
- **Диагностика и обратная связь.** Закрытие уведомления о диагностике
  сохраняется при повторном открытии меню; фон развёрнутой карточки обратной
  связи стал единым. Улучшено завершение отменённых загрузок оформления.

### Установка и обновление

Для Chrome, Edge или Opera распакуй соответствующий GitHub ZIP, открой
`chrome://extensions`, `edge://extensions` или `opera://extensions`, включи режим
разработчика и выбери «Загрузить распакованное расширение» → папку с
`manifest.json`. Для обновления замени файлы в прежней папке и нажми «Обновить»,
сохранив установленное расширение и его локальные настройки.

**Firefox:** обычная установка доступна через
[Firefox Add-ons](https://faceit.eelworg.ru/r/PmGEU43eYuhbEofi).
Firefox ZIP не подписан Mozilla и подходит для временного тестирования через
`about:debugging` → «Этот Firefox» → «Загрузить временное дополнение».
Минимум: Firefox 140; заявленный минимум Android — 142.

Некоторые функции требуют подключения FACEIT и/или Absolute Premium; условия
показаны в расширении. FACEIT Absolute — независимый проект, не связанный с FACEIT.

## English

**In-match power saving · Clan-tag placement · Refined customization**

### Changes since 2.4.0

- **Power saving during your match.** Disable decorative effects or pause
  extension features for the match, then restore them when it ends.
  CPU/GPU savings have not been measured.
- **Own clan-tag placement.** Place it on or below the avatar, with a vertical
  adjustment for on-avatar placement. Improved player-name spacing.
- **Profile customization.** Improved grayscale for icons, navigation and
  match history; disabling it restores configured colors and settings.
- **Matchmaking and current-match controls.** Long custom labels wrap onto
  multiple lines, preserving accents and readable notices.
- **Audio and navigation.** Fixed stale extension contexts after reload.
  The separate sound-library website supports expanded cards and profile styling.
- **Diagnostics and feedback.** Dismissing the diagnostics notice persists
  when reopening the menu. The expanded feedback card uses a consistent
  background. Cancelled customization uploads settle more reliably.

For Chrome, Edge, or Opera, extract the corresponding GitHub ZIP, open
`chrome://extensions`, `edge://extensions`, or `opera://extensions`, enable Developer
mode and choose **Load unpacked**. Select the folder containing `manifest.json`.
To update, replace files in that same folder and click **Reload**, keeping the
extension installed to preserve local settings.

temporary testing uses `about:debugging` → **This Firefox** → **Load Temporary
Add-on**. Minimum Firefox version: 140; declared Android minimum: 142.

Some features require a connected FACEIT account and/or Absolute Premium, as
indicated in the extension. FACEIT Absolute is an independent project.
