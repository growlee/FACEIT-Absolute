## Русский

**FACEIT Absolute 2.1.0** — расширение для своего фона и оформления профиля FACEIT в Chrome, Firefox, Edge и Opera.

### Что нового

- MP4-превью в окне расширения: посмотри оформление перед выбором.
- Последние исправления фона профиля и настроек оформления после версии 2.0.0.

### Установка

Проще всего установить из **[Chrome Web Store](https://chromewebstore.google.com/detail/faceit-absolute/immjippehkkpphboodnbbchgmpabmpec)** или **[Firefox Add-ons](https://addons.mozilla.org/en-US/firefox/addon/faceit-absolute/)**. Версии в магазинах могут отличаться от этого GitHub-релиза.

Для ручной установки выбери архив своего браузера:

| Браузер                                            | Файл                                                                                                                                       |
| -------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| Chrome                                             | [FACEIT-ABSOLUTE-2.1.0-Chrome.zip](https://github.com/growlee/FACEIT-Absolute/releases/download/v2.1.0/FACEIT-ABSOLUTE-2.1.0-Chrome.zip)   |
| Edge                                               | [FACEIT-ABSOLUTE-2.1.0-Edge.zip](https://github.com/growlee/FACEIT-Absolute/releases/download/v2.1.0/FACEIT-ABSOLUTE-2.1.0-Edge.zip)       |
| Opera                                              | [FACEIT-ABSOLUTE-2.1.0-Opera.zip](https://github.com/growlee/FACEIT-Absolute/releases/download/v2.1.0/FACEIT-ABSOLUTE-2.1.0-Opera.zip)     |
| Firefox — только тестирование / загрузка в магазин | [FACEIT-ABSOLUTE-2.1.0-Firefox.zip](https://github.com/growlee/FACEIT-Absolute/releases/download/v2.1.0/FACEIT-ABSOLUTE-2.1.0-Firefox.zip) |

В Chrome, Edge или Opera распакуй ZIP, открой страницу расширений, включи режим разработчика и выбери «Загрузить распакованное расширение». Укажи папку с `manifest.json`. Для обновления распакуй новый архив в прежнюю папку и нажми «Обновить»; сохраняй установленное расширение, чтобы не потерять его локальные настройки.

**Firefox ZIP не подписан Mozilla и не подходит для постоянной установки в обычный Firefox. Используй Firefox Add-ons.** Архив предназначен для тестирования и ручной загрузки в магазин.

## English

**FACEIT Absolute 2.1.0** is a browser extension for custom FACEIT profile backgrounds and styling in Chrome, Firefox, Edge, and Opera.

### What's new

- MP4 previews in the extension popup: preview a style before choosing it.
- The latest profile-background and customization fixes since version 2.0.0.

### Installation

The easiest way to install is through **[Chrome Web Store](https://chromewebstore.google.com/detail/faceit-absolute/immjippehkkpphboodnbbchgmpabmpec)** or **[Firefox Add-ons](https://addons.mozilla.org/en-US/firefox/addon/faceit-absolute/)**. Store versions may differ from this GitHub release.

For a manual installation, choose the archive for your browser:

| Browser                                   | File                                                                                                                                       |
| ----------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| Chrome                                    | [FACEIT-ABSOLUTE-2.1.0-Chrome.zip](https://github.com/growlee/FACEIT-Absolute/releases/download/v2.1.0/FACEIT-ABSOLUTE-2.1.0-Chrome.zip)   |
| Edge                                      | [FACEIT-ABSOLUTE-2.1.0-Edge.zip](https://github.com/growlee/FACEIT-Absolute/releases/download/v2.1.0/FACEIT-ABSOLUTE-2.1.0-Edge.zip)       |
| Opera                                     | [FACEIT-ABSOLUTE-2.1.0-Opera.zip](https://github.com/growlee/FACEIT-Absolute/releases/download/v2.1.0/FACEIT-ABSOLUTE-2.1.0-Opera.zip)     |
| Firefox — testing / store submission only | [FACEIT-ABSOLUTE-2.1.0-Firefox.zip](https://github.com/growlee/FACEIT-Absolute/releases/download/v2.1.0/FACEIT-ABSOLUTE-2.1.0-Firefox.zip) |

In Chrome, Edge, or Opera, extract the ZIP, open the extensions page, enable developer mode, and choose **Load unpacked**. Select the folder containing `manifest.json`. To update, extract the new archive into the existing folder and click **Reload**; keep the extension installed to preserve its local settings.

**The Firefox ZIP is unsigned and cannot be permanently installed in standard Firefox. Use Firefox Add-ons.** The archive is provided for testing and manual store submission.

[Installation steps and how to change your FACEIT background](https://github.com/growlee/FACEIT-Absolute#installation) · [Background library](https://faceit.eelworg.ru/profile-library/)

All four packages are built from source commit `e28f45d5baf9f582e0c158363557e4302335a54f`, with manifest version `2.1.0` and build stamp `e28f45d5`. The Firefox package uses the existing Gecko ID and background-script compatibility manifest. This public repository distributes extension packages; private source history and server files are excluded.

Validation: release metadata, secret scan, Firefox DOM safety, extension security boundaries, scoped formatting, and ESLint passed. Independent verification passed for the exact source, Chrome and Firefox archives, platform manifests, and one real Firefox addon offline content-script/background messaging smoke in headless Camoufox. Known validation limits in unchanged source: the full test chain stops at `content.js`'s architecture line limit (2002 versus 1995); TypeScript reports four `unknown` property errors in `background.js` lines 3922–3931; the final profile-background static check fails its storage-listener ordering assertion. Full-suite and TypeScript success are not claimed. Package checks and the offline smoke do not establish authenticated FACEIT LIVE behavior or installed Chrome runtime acceptance.
